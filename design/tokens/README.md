# Design tokens

Los tokens de ejecución viven en `tokens.css` y son la fuente central para colores, tipografía, espaciado, radios y sombras. Tailwind referencia estas variables en `apps/desktop/tailwind.config.ts`.

La paleta prioriza azul y cian para acciones, suma violeta para profundidad, conserva el coral para acentos puntuales y reserva verde, ámbar y rojo para estados semánticos. Los gradientes son controlados y nunca sustituyen la jerarquía o la legibilidad.
